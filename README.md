# Fallen Necromer — documentation

Documentation HTML publique, séparée du dépôt privé du jeu.

[Lire la documentation](https://safylos.github.io/FallenNecroma-docs/)

Les 44 pages conservent leur format HTML et leurs captures. Les archives
techniques, les sources du jeu et les rapports internes ne sont pas publiés.
Certaines références à ces fichiers privés sont donc désactivées dans cette édition.

Publication GitHub Pages depuis la branche `main`, dossier racine, sans Jekyll.
Les médias sont des fichiers ordinaires de ce petit dépôt, sans Git LFS.

La navigation est organisée en dossiers et sous-pages. Chaque créature propose Modèle, Attaques, Animations, IA et version ombrale. Le menu, le fil d’Ariane et les liens entre rubriques restent présents sur toutes les pages.
